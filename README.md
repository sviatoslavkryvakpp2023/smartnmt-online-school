# SmartNMT — онлайн-школа підготовки до НМТ

SmartNMT — це frontend вебзастосунок онлайн-школи для підготовки до НМТ.  
Система дозволяє переглядати курси, записуватися на навчання, імітувати оплату, проходити уроки, виконувати завдання, відстежувати прогрес та працювати з адміністративною панеллю.

## Стек технологій

- React
- Vite
- React Router
- JavaScript
- CSS
- LocalStorage

## Основний функціонал

- головна сторінка онлайн-школи;
- каталог курсів;
- сторінка курсу;
- сторінка уроку;
- кабінет учня;
- кабінет викладача;
- адміністративна панель;
- симуляція оплати;
- контроль доступу до уроків;
- відстеження прогресу.

## Ролі користувачів

- Учень — проходить курси та виконує завдання.
- Викладач — переглядає навчальні матеріали та інформацію про курси.
- Адміністратор — керує курсами, користувачами та оплатами.

## Запуск проєкту

```bash
npm install
npm run dev


## Адміністративна панель

Адміністративна панель SmartNMT дозволяє переглядати статистику системи, список курсів, користувачів, оплат та журнал дій. Адміністратор може контролювати роботу платформи, керувати курсами, переглядати користувачів, відстежувати статуси оплат та аналізувати основні процеси онлайн-школи.
